# Simple Order Form

Bài thực hành tạo form HTML cơ bản gồm:

- Danh sách lựa chọn bằng `<select>` và `<option>`.
- Lựa chọn số lượng bằng radio button.
- Các ô nhập Name, Email và Phone Number.
- Nút Submit.
- Font chữ `"Lucida Grande", "Lucida Sans Unicode", Tahoma, sans-serif` áp dụng qua class `.wufoo`.

Mở file `simpleform.html` bằng trình duyệt để xem kết quả.
